# BMI Calculator (Python)

A simple command-line BMI (Body Mass Index) calculator built with Python.

## Features
- Takes weight (kg) and height (meters) as input
- Calculates BMI using: BMI = weight / (height x height)
- Shows category: Underweight, Normal, Overweight or Obese
- Input validation: rejects letters, zero and negative values

## How to Run
1. Install Python 3
2. Open a terminal in this folder
3. Run: `python bmi_calculator.py`
4. Enter your weight and height when asked

## BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25 - 29.9 | Overweight |
| 30 and above | Obese |

## Example Output

```text
Enter weight in kg: 70
Enter height in meters: 1.75
Your BMI is 22.86 (Normal)
```
