# Chat Application (Python)

A simple command-line chat application using sockets and threading.

## Features
- Server script that listens for client connections
- Client script that connects to the server
- Real-time messaging between two clients
- Timestamp on every message, for example [12:24] bob: ntg
- Notification when a user joins or leaves the chat
- Runs on one machine using localhost

## How to run
1. Start the server: python server.py
2. Open two more terminals and run: python client.py
3. Enter a name in each client and start chatting
4. Type quit to leave the chat
